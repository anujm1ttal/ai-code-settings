# Skill Abstract: Documentation Standards & Maintenance (L0)

**Purpose**: Generate, update, and audit project documentation for staleness and accuracy.

**Core Logic**:
- **Gated Deliverable**: Docs are part of the auditor's exit review — stale docs block `[x]`.
- **Density Over Length**: Bullets/tables over prose; no LLM filler or conversational padding.
- **Audience-Aware Templates**: README, ARCH.md, and stakeholder guides each have a defined required-section order.

**Constraint**: Do NOT use for raw brainstorming/research notes unless formalizing them into permanent docs.
