# Skill Abstract: Verification Gate (L0)

**Purpose**: Mandatory evidence-first verification before claiming any status or marking tasks done.

**Core Logic**:
- **Iron Law**: NO COMPLETION CLAIMS WITHOUT FRESH VERIFICATION EVIDENCE in the current message.
- **The Gate Function**: Identify command → Run fresh → Read full output → Verify against metric → Only THEN make the claim.
- **Anti-Rationalization**: Rejects "should pass," "probably," or "mental models" as valid evidence.

**Constraint**: Violating the letter of this rule is violating the spirit. No exceptions.
