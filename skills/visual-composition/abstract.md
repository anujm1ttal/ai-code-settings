# Skill Abstract: Visual Composition (L0)

**Purpose**: Hierarchy, layout, and brand governance across slides, reports, and dashboards — enforces "Hierarchy First" design and accessibility.

**Core Logic**:
- **Hierarchy First**: One focal point per screen; density limits per medium (slide/dashboard/report); grid + spacing discipline.
- **Accessibility Non-Negotiables**: Contrast ≥4.5:1 body / ≥3:1 large text, min 12pt body font, no color-only meaning encoding.
- **Anti-Slop Deny List**: Rejects banned fonts (Inter/Roboto/Arial/Segoe UI), centered-everything layouts, accent-line-under-title, cookie-cutter card grids.

**Constraint**: Do NOT use for technical implementation (python-pptx code, Power BI theme JSON) — refer to specialized document skills for those.
