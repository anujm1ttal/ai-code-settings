# Skill Abstract: Project Planner (L0)

**Purpose**: Phased roadmaps, dependency mapping, and atomic task decomposition for the Strategist.

**Core Logic**:
- **ROI-Driven Escalation**: Prioritize Tier 1 Metadata → Tier 2 Logic → Tier 3 Full Content.
- **Phased Delivery**: Max 3-4 phases. Each must be independently valuable and have numeric metrics.
- **Atomic Tasks**: Every TODO item must be atomic, measurable, and touch <= 8 files.

**Constraint**: NO PLACEHOLDERS. Vague directives or aspirational labels result in plan rejection.
