# Skill Abstract: Power BI Report Patterns (L0)

**Purpose**: Theme-driven page layout, visual selection, and mobile-first design for Power BI report front-ends.

**Core Logic**:
- **Theme-Driven**: All styling from theme JSON — no ad hoc formatting.
- **Density Discipline**: 3–7 pages per report, max 8 visuals per page; measures over raw columns.
- **Mobile Mandatory**: Every report ships an explicit, manually-designed mobile layout.

**Constraint**: Do NOT use for backend data modeling or DAX authoring — use `dax-modeling` instead.
